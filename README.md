# Bakery Ordering System
**Note:** This project was originally developed for CPSC 210 - Software Constructure in 2024. It has been migrated here for portfolio purposes.

## Streamlined order management in a bakery

**What will the application do?**

The application will function as an ordering system for a bakery. Users can browse a list of available food items, add items to their order, leave notes for the bakery, and place an order. (X could be food items, and Y could be the list of my orders) Once an order is places, the selected items will be cleared from the current order list and moved to a receipt, providing a clear confirmation of the placed order.

**Who will use it?**

The primary users will be customers of the bakery who want to place orders. Additionally, bakery staff may use it to manage orders and track customer requests.

**Why is this project of interest to you?**

This project is of interest to me because it combines my passion for both software development and cooking/baking. Creating a practical application that could be used in a real-world setting allows me to apply my Java programming skills in a meaningful way, exploring ordering management systems.


## User Stories
- As a user, I want to be able to view a list of available food items
- As a user, I want to be able to add food items to my order
- As a user, I want to be able to leave additional notes
- As a user, I want to be able to place my order
- As a user, I want to be able to view what order I made so far
- As a user, when I select the quit option from the application menu, I want to be reminded to save the data (workers list, available items and the placed order list), and have the option to do so or not
- As a user, when I start the application, I want to be given the option to load the data (workers list, available items and the placed order from the file)



# Instructions for Grader
- "Adding multiple Xs to a Y"
1. Click the ‘Worker Menu’. Then, if you click the ‘New Worker’ button, enter the name and PIN, and you will be added to the worker list. After logging in, click the ‘Add Item’ button, you can add an item to the items list. 
2. Click the ‘Order’ button to add items by selecting from the available items list. Click the ‘Add Item’ button to add an item to the cart and add notes by typing in the text field. Then, click the ‘Place Order’ button.
- You can generate the first required action related to the user story "adding multiple Xs to a Y" by clicking the 'Worker Menu', logging in, and clicking the 'Remove' button to remove an item from the available items list.
- You can generate the second required action related to the user story "adding multiple Xs to a Y" by clicking the ‘Order’ button in the main menu. Then, click the 'Alphabetical Order' button to display items in alphabetical order.
- You can locate my visual component by clicking the ‘How to Use’ button in the main menu.
- You can save the state of my application by clicking the ‘Exit’ button. It will ask if you want to save the data.
- You can reload the state of my application by starting the GUI. A pop-up will appear asking if you want to load previous data. To load the data, click "Yes."
